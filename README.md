# PAEX Avaliações 2026

Interface responsiva para acompanhar a análise de mérito do Edital PAEX 07/2026.

## Incluído nesta versão

- Painel mestre com visão de propostas, andamento da banca e alertas para terceiro parecer.
- Visão do avaliador com fila individual de propostas e formulário de pontuação.
- Critérios de mérito organizados a partir da matriz de avaliação do edital.
- Layout responsivo para computador e celular.

## Próximas etapas

Esta primeira versão concentra a interface navegável. A evolução operacional adicionará login por e-mail e senha, banco de dados, cadastro de avaliadores, importação de propostas habilitadas, distribuição de pareceres e histórico de auditoria.

## Executar localmente

Abra `index.html` em um navegador. O projeto não exige dependências nesta etapa.
